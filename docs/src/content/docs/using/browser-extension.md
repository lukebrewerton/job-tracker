---
title: Browser extension
description: Saving a job from its posting with one click.
---

:::note[Coming soon]
The Firefox extension is being built. This page will cover installing it and setting it up.
:::

The extension adds a button to Firefox's toolbar. On a job posting, select it and Job
Tracker's [new job form](/using/adding-a-job/#starting-from-a-posting) opens with the
posting's link and title already filled in. You'll tell it your instance's address once,
in its options.
